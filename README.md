# AmazonPage

用于集中存储和发布多个静态页面（GitHub Pages）。

## 页面目录

| 页面 | 目录 | 访问地址 |
|------|------|----------|
| FBA 售后功能顾问页 | `fba-advisor-page/` | [访问](https://liya-liang.github.io/AmazonPage/fba-advisor-page/) |
| FBA 卖家增长工具箱 | `fba-toolkit-page/` | [访问](https://liya-liang.github.io/AmazonPage/fba-toolkit-page/) |

## 约定

- 每个页面放在独立子目录，并包含自己的 `index.html`
- 不把单个业务页面直接作为仓库根目录首页，便于后续扩展多个页面
- 新页面使用 kebab-case 命名目录，如 `page-name/`
- 详细规范见 [AGENTS.md](./AGENTS.md)
