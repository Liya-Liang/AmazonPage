💬 FEATURE 01 — 品牌主实时支持 (Brand Integration)

本土客服实时答疑，最后一刻挽留订单

品牌主实时支持（BI）是亚马逊商品支持（Product Support）的核心功能之一。当消费者在退货流程中遇到问题时，系统会自动将消费者转接到您的品牌客服团队，让您有机会在退货发生前直接沟通、解决问题，挽留订单。

📋 功能是什么？长什么样？

📞实时转接客服

消费者在"获取产品支持"页面可以选择在线联系卖家客服或留下电话等待联系。亚马逊来电后自动转接到品牌主客服，品牌主不会直接看到顾客电话，保护双方隐私。

🛡️三大触达入口

订单页面：顾客点击"获取产品支持"直达。
退货流程：选择退货原因后自动弹出支持页面。
客服中心：顾客选择有问题的订单后跳转。

🌍多站点覆盖

适用于美国站、加拿大站、英国站、法国站、意大利站、西班牙站、德国站、瑞典站、荷兰站、比利时站、波兰站。需要品牌主具备本土语言能力和当地时间在线支持的客服团队。

⚡前置条件

需要先开通"联系制造商"功能，然后才能激活品牌主实时支持。适用于已完成品牌注册的品牌主卖家，完全免费。

1

确认品牌注册

确保您已完成亚马逊品牌注册（Brand Registry），这是使用商品支持功能的前提。

2

开通"联系制造商"功能

3

💰 FEATURE 02 — 部分退款 (Partial Refund)

灵活退款不退货，降低退货成本

部分退款功能允许卖家向消费者提供"保留商品并获得部分退款"的选项，无需退还商品。消费者在退货流程中可以选择接受部分退款，卖家节省退货处理、仓储和移除费用。

📋 功能是什么？长什么样？

💳消费者体验流程

买家表示退货意向 → 提供退货原因 → 选择"退款"选项 → 系统提供"保留商品并获得部分退款"的选项 → 买家选择"部分退款"。整个流程简洁流畅，消费者无需寄回商品即可获得退款。

⚙️卖家自主设置

卖家可以为每个 ASIN 单独设置退款比例，也可以为所有 ASIN 设置统一折扣。支持通过 CSV 文件批量上传，最多可上传 50,000 个 ASIN。默认关闭，需手动开启，可随时停止。

🛡️防滥用机制

亚马逊已设置精准筛选条件，仅面向不存在滥用行为历史的消费者显示部分退款选项。消费者在购买时不会知道该商品是否提供此选项，避免滥用行为。

🌐适用范围

站点：美国站、欧洲五国站（英/德/法/意/西）
物流模式：FBA
商品要求：非危险品、非卫生用品、非不可退货商品

💸

⏱️

🎛️

📊

亚马逊物流销售佣金保持不变，卖家仍可收到销售佣金退款（减去管理费用）

🚀 如何开启？

1

进入 FBA 设置

从卖家平台的"设置"下拉菜单中，选择"亚马逊物流"。

2

找到部分退款设置

滚动到"FBA 退货评估与所有权设置"部分，点击"部分退款"旁边的"编辑"。

3

选择启用方式

可选择为所有 ASIN 启用并设置统一折扣，或上传 CSV 文件为选定 ASIN 设置不同退款比例（最多 50,000 个 ASIN）。

4

保存并追踪

点击"保存"，更改立即生效。在 FBA 退货页面点击"管理退货订单"，查看"退货状态"列中标记为"完成 - 不用退货"的订单。

💡 小贴士：建议先从退货率较高的 ASIN 开始试点，设置合理的退款比例（如商品售价的 10%-30%），观察效果后再逐步扩大范围。

🔧 FEATURE 03 — 零配件补发计划 (Replacement Parts Program) NEW

缺失零件不退货，补发配件留住客户

零配件补发计划是亚马逊商品支持的最新功能。当消费者收到的商品存在零配件缺失或损坏时，可以在退货窗口内直接免费申请补发配件，无需退回整个商品。这大幅减少了因小零件问题导致的整件退货。

📋 功能是什么？长什么样？

🔩解决的核心问题

大量退货仅仅因为消费者找不到安装答案、缺失或损坏了一个小零件就退回整个商品。零配件补发让消费者可以直接申请缺失的配件，避免不必要的整件退货。2024年已有 40 万+品牌注册，成功阻止了 1470 万次退货。

📦运作方式

卖家需要将零配件作为独立 ASIN/SKU 上架，并与父 ASIN 关联。消费者在"获取产品支持"页面可以看到可申请的零配件列表，选择需要的配件后由卖家通过 FBM（卖家自配送）完成配件订单。

📋配送要求

父 ASIN/SKU：必须是 FBA 配送，FBM 的 ASIN 不符合注册资格。
零配件 ASIN/SKU：FBA 卖家必须通过 FBM（卖家自配送）完成配件订单。

🌐适用范围

适用于美国站、加拿大站、英国站、法国站、意大利站、西班牙站、德国站。需要品牌主卖家身份，完全免费。

🎯 对卖家的好处

📉

避免因小零件问题导致的整件退货，2024年全球已阻止 1470 万次退货

💰

降低退货成本

补发一个小配件的成本远低于处理一次完整退货的运输、仓储和移除费用

😊

提升客户体验

消费者无需退回整个商品，快速获得缺失配件，满意度大幅提升

⭐

保护产品评分

减少因退货产生的差评和高退货率标签风险，维护商品详情页健康度

🚀 如何开启？

1

准备零配件 ASIN

将商品的零配件（螺丝、支架、遥控器等）作为独立 ASIN/SKU 上架，每个配件需要有独立的 UPC 编码。

2

进入商品支持注册门户

在卖家平台找到商品支持一站式注册门户，选择"零配件补发计划"功能。

3

关联父 ASIN 与配件 ASIN

按照页面提示，将零配件 ASIN 与对应的父 ASIN 进行关联，设置配件信息。

4

通过 FBM 配送配件订单

消费者申请配件后，卖家通过卖家自配送（FBM）完成配件订单的发货。

💡 小贴士：建议优先为退货原因中"缺失零件"或"损坏零件"占比较高的 ASIN 开通此功能。结合售后视频和产品操作文档，可以进一步降低因安装问题导致的退货。

📦 FEATURE 04 — 货件差异主动调查 (Proactive MFI Claim) 自动注册

无需手动申请，官方主动开启差异调查

亚马逊全面升级高客单价商品入库计划！针对包含价值 $50/€49/£40 或以上商品的货件，在货件运输完成后出现差异时，亚马逊将自动为您发起调查并处理异常，无需您手动开 Case。

📋 功能是什么？长什么样？

🔍主动调查机制

当您的货件在运输完成（Closed）后出现与计划的差异时，亚马逊会主动发起调查并处理异常，大幅减少您查验和手动开 Case 的繁琐步骤。无需动手，系统自动追踪。

📋自动建案追踪

系统自动为您创建调查 Case，并在"货件一览"页面清晰标签区别，让进度主动出现在您眼前。Case 主题为"FBAXXX - Missing Item From Inbound"，与卖家手动创建的差异调查 Case 格式相同。

⚡更快赔付

处理周期从原来的 45 天缩短至 30 天内，赔付更快。无需再使用防篡改胶带，也不用额外确认调查。某些案例将通过自动完成 Case 解决，无需您提供任何证据。

✅资格条件

卖家维度：过去12个月平均 ASP 高于 $50/€49/£40，包括之前注册过 HASPIP 的卖家。
货件维度：包含至少一件 ASP 高于 $50/€49/£40 的高客单价商品。

🚀 如何查看和追踪？

1

通过库存管理查看

打开"库存" → 选择"货件" → 查看"预计商品数量"和"找到的商品数量"之间的差异 → 点击"追踪货件" → 在"货件一览"页面点击"物品信息" → 查看"已提交问题"。

2

通过支持问题查看

路径：帮助 → 管理支持问题 → 主题为"FBA - Missing Item From Inbound"。调查完成后，亚马逊会更新 Case 详情。

💡 重要提示：您仍然保留自己开启 MFI 调查案例的权利。对于不适用自动解决的 Case，可能仍需要您提供相关证据（如 POD、收据等）用以后续调查。建议保留好每次发货的相关凭证。

❓ 常见问题

此功能需要付费吗？

不需要。此功能完全免费，自动注册，无需您采取任何行动。

我是否保留自己开启 MFI 调查案例的权利？

是的。您仍然可以自行发起 MFI 调查。

使用此功能的资格标准是什么？

卖家维度：过去12个月平均 ASP 高于 $50/€49/£40，包括之前注册过高客单价商品入库计划（HASPIP）的卖家。
货件维度：包含至少一件 ASP 高于 $50/€49/£40 的高客单价商品。

与手动的 MFI 申诉流程有什么区别？

1) 对于存在差异的货件，亚马逊将自动代表您创建调查 Case，节省您的时间和精力；2) 某些案例将通过自动完成 Case 解决和处理，无需您进一步提供任何证据；对于不适用自动解决的 Case，可能仍需要您提供相关证据（如 POD、收据等）用以调查。
